## Function and Content

- Same URL, title, canonical and index policy. Adds component duration and a separate fixed-day breakdown beside decimal equivalents. The main seconds-to-hours answer emphasizes HMS for readability; decimal hours remain immediately below it.
- Adds decimal-hours-to-seconds direction. Decimal 1.5 hours is 1h 30m, while 1.30 hours is 1h 18m. The example default becomes 3,600 seconds / one hour instead of the old one-second generic example.
- Supports nonnegative ordinary decimal inputs up to six fractional places. Integer microseconds preserve boundary remainders, such as 59.999999 seconds versus 60 seconds. The documented upper limit is 9,007,199,254.740991 seconds; overflow, excess precision, malformed/scientific/negative values and blanks fail explicitly. This is not unbounded arbitrary-precision conversion.
- Exact supported component/total-second text is separate from rounded repeating decimal hours/minutes. 356,442 seconds decomposes as 99h 0m 42s or 4d 3h 0m 42s. No pie or numeric-input comparison is invented for these equivalent representations.
- Clear removes stale summary/details; direction labels and unit hints update. A reproduced large-number mobile overflow is fixed with dashboard-scoped minimum-width/grid/wrapping rules, preserving other pages' visual rules and the theme.
- Original formula, worked examples, decimal-hour distinction, precision limits and fixed-duration assumptions. [NIST's unit table](https://www.nist.gov/pml/special-publication-811/nist-guide-si-chapter-5-units-outside-si) supports the 60/3,600/86,400-second unit relationships. No time-zone, daylight-saving, leap-second or payroll calculation is claimed. Reciprocal contextual routing with Time Duration distinguishes total-duration conversion from two-endpoint clock arithmetic.

The existing Calculate event name and path remain; this page's engine identifier becomes `seconds_hours_advanced` instead of generic `linear_convert`. No Analytics account setting changes. Synthetic browser tests block Analytics requests.
