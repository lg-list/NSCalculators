# Northstar Calculators V2

A static, US-focused SEO calculator site starter rebuilt from scratch.

## Included
- 50 calculator pages
- 4 category hubs
- Homepage search
- 4 trust/policy pages
- 404 page
- Purpose-built JavaScript engines (no generic A+B placeholder)
- Unique title, description, formula, worked example and FAQ copy per calculator
- Related-calculator internal links
- JSON-LD WebPage schema
- Canonical tags
- sitemap.xml
- robots.txt
- Responsive CSS
- Keyword Planner metadata for the high-priority keywords from the supplied dataset
- GitHub Pages / Cloudflare Pages-ready `dist/`

## Deploy
Upload the contents of `dist/` to your static host.

Before deployment, replace every occurrence of:

`https://YOUR-DOMAIN.com`

with your real HTTPS domain.

## SEO / quality rule
Do not add pages merely to increase URL count. Every new calculator should have:
1. A distinct search intent
2. A real formula or real lookup data
3. Useful inputs
4. Formula and assumptions
5. A worked example
6. Appropriate related links
7. Verification against authoritative sources where the topic is safety-, finance-, construction-, fitment- or code-sensitive

## Important
Google Ads competition in the JSON is an advertising signal, not organic keyword difficulty.
